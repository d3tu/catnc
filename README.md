# CatNC - CNC Catalog Generator

> **Portfolio Note**: This repository is a public project created for technical showcase, learning and portfolio purposes.

**CatNC** is a TypeScript tool using PDFKit that converts CNC files into PDF catalogs with 2D part renders for technical support.

---

## Motivation

As a former CNC operator and 2D draftsman, finding legacy files was a frequent bottleneck. CatNC automates generating visual PDF catalogs so operators and support teams can quickly locate past programs.

---

## Tech Stack

- **TypeScript** - Type safety and engine logic.
- **PDFKit** - Vector rendering and PDF generation.
- **Node.js** - File system management and runtime.

---

## Installation and Usage

```bash
git clone https://github.com/d3tu/catnc.git
cd catnc
npm install
npx tsx index.ts
```
